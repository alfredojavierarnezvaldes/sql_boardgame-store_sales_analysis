# SQL BOARDGAME SALES ANALYSIS PROJECT

## Project Overview.
This project simulates a small online boardgame store database and analyzes sales, customers, orders, and payments using PostgreSQL.

The main objective is to demonstrate my ability to:

- Design and work with a relational database
- Write SQL queries with progressively increasing complexity
- Extract business insights from data

---
  
## Tools & Technologies.
- PostgreSQL
- pgAdmin 4
- SQL (JOINs, aggregations, subqueries)
- Jupyter Notebook (for documentation and analysis)
- GitHub
  
---

## Database Structure.
The database includes the following tables:

- tegories
- customers
- order_items
- orders
- payments
- products

Relationships between tables are based on primary and foreign keys.

---

## Analysis & Queries.

The analysis includes:

- Basic queries (SELECT, WHERE, ORDER BY)
- Aggregations (SUM, COUNT)
- JOINs across multiple tables
- Subqueries
- Business-focused questions related to revenue, customer behavior, and payment methods

## Key Insights.

The analysis addressed several business questions, including:

- Cochabamba generated the highest revenue among the departments analyzed.
- Carla Butrón was the customer with the highest total spending, with 5,300.
- QR was the most frequently used payment method, with 11 transactions.
